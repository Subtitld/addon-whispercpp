pywhispercpp 1.5.1 vendors pybind11 as a git submodule and builds its
extension module with it (`pybind11_add_module(_pywhispercpp ...)`).
pybind11 is header-only, so its code is compiled into
bin/_internal/_pywhispercpp.* on every platform. No separate pybind11 file
ships.
