GCC runtime libraries — Linux builds only
Licence: GPL-3.0-or-later WITH GCC-exception-3.1 (see COPYING3 and
COPYING.RUNTIME, fetched from the GCC source tree)
Upstream: https://gcc.gnu.org/

  * libgomp (GNU OpenMP) — shipped as pywhispercpp.libs/libgomp-*.so.1.0.0 by
    the pywhispercpp manylinux wheel (auditwheel-vendored); whisper.cpp uses it
    for its CPU thread pool.
  * libstdc++ and libgcc_s — copied from the build machine by PyInstaller,
    because the whisper.cpp libraries are C++.
  * libgfortran — shipped inside numpy.libs by the numpy wheel for OpenBLAS
    (CentOS 7's libgfortran5-8.3.1-2.1.1.el7, i.e. GCC 8.3.1); numpy's own
    LICENSE.txt (../numpy-*/) lists it as well.

libquadmath, which numpy.libs also ships, is NOT covered here: it is LGPL,
see ../libquadmath/.

The GCC Runtime Library Exception permits propagating these runtime libraries
with independent code under terms of your choice when they were combined
through an Eligible Compilation Process, which is how they were built. They
are redistributed unmodified.
